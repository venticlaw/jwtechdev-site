What AWS certification should I start with?

Start with the AWS certification that matches your current background, not the one that sounds most impressive.

If you are brand new to cloud, AWS Certified Cloud Practitioner is usually the cleanest first step. If you already understand basic infrastructure, Solutions Architect Associate may be a better target. If your role is AI-focused, AWS Certified AI Practitioner can help, but it should not replace cloud fundamentals.

Simple decision path

  • Brand-new learner: start with Cloud Practitioner.
  • Technical beginner with projects: consider Solutions Architect Associate.
  • AI-focused learner: consider AI Practitioner, then reinforce cloud fundamentals.

The mistake to avoid

Do not collect badges without projects. Every cert path should produce an artifact: a diagram, a README, a cost note, a security note, or a small working build.

Study prompt

Write down your current level, target role, and one project you can build while studying. Then pick the cert that supports that path.
