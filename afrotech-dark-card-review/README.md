# Dark Systems Business Card Family

Four readable business-card directions based on the selected black Executive Constellation concept.

1. Refined Constellation
2. Command Grid
3. Signal Path
4. Executive ID

Every direction uses the JWTechDev typography system: Roboto Condensed for display text, Roboto for supporting copy, and the approved mono family only for technical accents. The cards use Joshua "TechDev" Walker's exact Deloitte title and show 13+ years in technology based on an August 2013 HRsoft start.

Readability improvements include larger role text, shorter proof labels, stronger contrast, fewer competing elements, and a consistent information hierarchy. The selected dark back is shared across all four options.

The combined review image is `dark-card-family.png`. Individual PNGs and editable SVG sources are included in their respective folders.
